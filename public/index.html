About

Why use this API or Data?

Looking for reliable Sri Lankan holiday data? This API has you covered with fresh, accurate updates you can drop right into your app. JSON, CSV, ICS, XML? - We've got you covered!

  • Verified Data

    All holiday information comes directly from official Sri Lankan government sources, including the Ministry of Home Affairs and the Government Gazette — ensuring accuracy and trust you can rely on.

  • API + Data

    Access up-to-date Sri Lankan holidays through a simple, open-source API or download ready-to-use files in multiple formats. Perfect for seamless integration in any app or workflow.

  • Fast & Secure

    Built with Redis caching for lightning-fast responses and protected with API key authentication, the API ensures reliable, secure access every time.
